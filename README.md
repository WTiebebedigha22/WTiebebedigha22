## 👨🏽‍💻 About Me

I'm **Ware Tiebebedigha**, a software developer focused on building practical, user-centred applications across web and mobile.

I work across the product stack — from shaping interfaces and application architecture to building APIs, integrating databases, and connecting third-party services.

I enjoy turning complex ideas into software that feels straightforward to use. My projects span fintech, event technology, wellness, e-commerce, and machine learning.

- 🔭 **Currently building:** BraveVest, Lunora, and practical product experiences.
- 📱 **Mobile Development:** Flutter and Dart, with Firebase and Supabase integrations.
- 🌐 **Web Development:** React, TypeScript, JavaScript, Node.js, and Express.
- 🧠 **Exploring:** Machine learning and data-driven applications with Python.
- 🎨 **What I bring:** Product thinking, visual creativity, interface design, and hands-on implementation.
